# Repository Instructions

- Write repository documentation and commit messages in English.
- For new features, changes to the public data format, or other substantial work, use the grill-me workflow. Inspect the repository, resolve material questions one at a time, and obtain approval for the plan before implementation.
- Keep one scoped objective per plan. Document the intended behavior and its verification in `docs/PLAN.md`, then execute the approved steps. Pause between steps only when the user requests it or a material decision arises.
- Preserve UTF-8 spelling and distinguish sourced puzzle appearances from spelling examples. Check the cited puzzle data for every new appearance, and confirm each ending matches the letters of its term.
- Keep `README.md` and `glossary.json` in sync. Record verification results in `docs/PROGRESS.md` and update the architecture or modularity notes when their scope changes.
- Review the diff before committing and keep incidental files out of the repository.
